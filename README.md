# BasatiNA 🌊

(antes «Pedrito Control Río Arga»)

App de Android con el simulador de riadas del río Arga (del nacimiento a Funes).

- **Mapa** con ortofoto del IGN (PNOA) y zonas inundables calculadas con el MDT25 del IGN.
- **Previsión** con la lluvia de Open‑Meteo, descargada desde el propio móvil.
- **Prueba de conexión** con el SAIH Ebro.

Para jugar y aprender: ante riesgo real, haz caso siempre a los avisos oficiales (CHE, SOS Navarra 112, Ayuntamiento).

## Cómo se fabrica el APK
Cada vez que se sube un cambio, GitHub Actions lo compila solo (pestaña **Actions** → última ejecución → **Artifacts** → `ControlRioArga-APK`).
